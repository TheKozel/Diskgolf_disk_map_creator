# Diskgolf disk map creator
A web application that transforms uploaded GeoJSON data into a complete discgolf course map. It allows users to customize map symbology, manage the placement and appearance of individual features, and view detailed information about the generated map and its components.

The goal is to create a fully customizable, print-ready discgolf course map that can be accurately transferred onto a disc in many formats.

## Test Data

Real-world sample data from Discgolf Course Prostějov – Hloučela is available for testing. The dataset includes:

Disc golf course layout

Forest areas

Flight paths

Tee pads

River

Significant trees

Baskets

These real-world GeoJSON and JSON datasets can be used to explore the application's features and test the map generation workflow.
